# ワークフロー承認シート → マイチャット通知

対象スプレッドシート: `ワークフロー承認シート`
（ https://docs.google.com/spreadsheets/d/1YCn1SUWyAX8sTqqK6SMR0JUEbRCMBax9aWymMXe_zCc/edit ）

「ワークフロー申請ログ」シートが以下のタイミングで更新されたら、Gemini APIで
「考察」「承認にあたっての検討事項」を自動生成し、Chatworkの自分のマイチャットへ
リアルタイムで通知します。

- (A) 新規申請行が追加された（会社名・承認内容・申請内容が入力された）とき
- (B) 3次承認（最終承認）のチェックが入ったとき

このスクリプトはGoogle Apps Script（スプレッドシートのコンテナバインドスクリプト）
として動作します。GitHub Actionsではなく、スプレッドシート側で完結する仕組みです。
このディレクトリはソースの保管・レビュー用であり、実際に動かすには下記の手順で
対象スプレッドシートに手動で貼り付ける必要があります（Apps Script APIへの
自動デプロイはこのセッションのツールでは行えません）。

## セットアップ手順

1. 対象スプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. デフォルトの `コード.gs` の中身を、このディレクトリの `Code.gs` の内容で置き換える
3. `appsscript.json`（表示 > マニフェスト ファイルを表示、で表示される）の内容を
   このディレクトリの `appsscript.json` に置き換える
4. スクリプトエディタ左メニューの「プロジェクトの設定」→「スクリプト プロパティ」で
   以下を登録する（**コードに直接書かない**）
   - `GEMINI_API_KEY` : Gemini APIキー（未設定でも動くが、その場合は定型文フォールバックになる）
   - `CHATWORK_TOKEN` : マイチャットの送信先アカウントのChatwork APIトークン
   - `MYCHAT_ROOM_ID` : マイチャットのルームID
     （Chatworkでマイチャットを開いたときのURL `https://www.chatwork.com/#!ridXXXXXXXX` の数字部分）
5. スクリプトエディタで関数 `setupTrigger` を選択して一度だけ実行し、
   インストール型のonEditトリガーを作成する（初回のみ承認ダイアログが出るので許可する）
6. 動作確認: 関数 `testNotifyRow` を `testNotifyRow(36, "new")` のように直接実行し、
   マイチャットにメッセージが届くか確認する（`36` は実データがある行番号に置き換える）

## 実装前提（要確認）

このスクリプトは、スプレッドシートの元データをテキストとして解析した結果に基づいて
列構成を推定しています。実際のシートと以下の前提が一致しているか、貼り付け前に
必ず確認・調整してください（`Code.gs` 冒頭の定数を編集すればOKです）。

- シート名: `ワークフロー申請ログ`（申請ログ本体）, `承認権限マトリクス`（値引き等の承認権限ルール表）
  → 実際のタブ名が異なる場合は `Code.gs` の `WORKFLOW_SHEET_NAME` / `APPROVAL_MATRIX_SHEET_NAME` を修正
- 列順（A〜R列、18列）:
  `No | 申請日 | 申請者 | 会社名 | 承認内容 | 申請内容 | 商談議事録 | 受注予定月 | 希望納期 |
  1次承認担当者 | 1次承認チェック | 1次承認タイムスタンプ |
  2次承認担当者 | 2次承認チェック | 2次承認タイムスタンプ |
  3次承認担当者 | 3次承認チェック | 3次承認タイムスタンプ`
  → 列がずれている場合は `Code.gs` の `COL` オブジェクトを修正

## 通知が重複しない仕組み

同じ行に対して同じステージ（新規/最終承認）の通知は1回のみ送るよう、
`PropertiesService`（スクリプトプロパティ）に送信済みフラグを保存しています。
再送したい場合は、対象キー（`notified_new_row<行番号>` / `notified_final_row<行番号>`）を
スクリプトプロパティから手動削除してください。

## セキュリティ上の注意

- APIキー・トークンはすべてスクリプトプロパティに保存し、コードにはハードコードしていません。
- このスクリプトが叩く外部サービスは Gemini API と Chatwork API のみです。
